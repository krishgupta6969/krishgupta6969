## ⚙️ Animation setup

The animated header and typing text use external image-generation services.
The GitHub statistics cards are rendered by third-party services.
The contribution games require GitHub Actions to generate their SVG assets.
An image URL does not create an animation by itself.

### Enable the contribution snake

Create `.github/workflows/snake.yml` in this profile repository.

```yaml
name: Generate contribution snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - name: Generate snake animation
        uses: Platane/snk@v3
        with:
          github_user_name: krishgupta6969
          outputs: |
            dist/snake.svg
            dist/snake-dark.svg?palette=github-dark
      - name: Publish generated SVG
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### Run the workflow

1. Open the profile repository on GitHub.
2. Select the Actions tab.
3. Open the contribution snake workflow.
4. Select Run workflow.
5. Wait for the workflow to complete successfully.
6. Open the output branch.
7. Confirm that the generated SVG files are present.
8. Refresh the profile README.

### Pac-Man and Breakout

Pac-Man and Breakout are separate contribution visualisations.
They are not generated by the snake workflow above.
Configure their own workflows before relying on their image links.
Check that the output branch contains the exact SVG filenames.
If those assets are unavailable, remove the corresponding image sections.

## 🛡️ GitHub README compatibility

GitHub README files support Markdown and a limited subset of HTML.
They do not execute JavaScript embedded in README content.
They do not load arbitrary custom CSS.
They do not behave like a full interactive website.
Animated GIF and SVG images depend on the image host.
Third-party statistics services can have rate limits or outages.
Some counters may be cached and may not update immediately.
External services can change their URL formats or availability.
Keep important profile information in normal Markdown text.
Use images to enhance the content, not replace essential information.
